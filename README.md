# SNATCH — After Hours

A custom Shopify Online Store 2.0 theme for SNATCH (Cairo).

- `theme/` holds the theme source (layout, sections, snippets, templates, assets, config, locales).
- `theme/DESIGN.md` is the design contract: palette, type, components and motion.
- `dist/snatch-after-hours.zip` is the packaged theme, ready to upload in Shopify admin › Online Store › Themes › Add theme › Upload zip.

Signature pieces: a spotlight hero that follows the cursor over a Higgsfield-generated video loop, a once-per-visit vault-door curtain, a scroll-lit manifesto, a pinned sideways "Tonight's lots" walk, a colourway switcher that re-tints the room, and product grids that fold "Style - Colour" products into one card with live colour dots.

Libraries bundled in `theme/assets`: GSAP + ScrollTrigger and Lenis (smooth scroll). Fonts are self-hosted: Bodoni Moda, Instrument Sans, JetBrains Mono (SIL OFL).
